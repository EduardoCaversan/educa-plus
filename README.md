## 🌍 Sobre o Projeto

O **Educa+** é uma aplicação web desenvolvida com o objetivo de facilitar o acesso a conteúdos educacionais gratuitos disponíveis na internet, especialmente no YouTube.

A plataforma organiza cursos por categoria, permitindo que usuários encontrem conteúdos de forma simples, rápida e intuitiva.

---

## 🎯 Objetivo

Este projeto foi desenvolvido como parte da disciplina **Programação Web Front-end**, com foco na aplicação prática de conceitos fundamentais de desenvolvimento web.

Além disso, o projeto contribui diretamente com:

### 📚 ODS 4 – Educação de Qualidade

> Garantir educação inclusiva, equitativa e de qualidade, promovendo oportunidades de aprendizagem ao longo da vida para todos.

---

## ✨ Funcionalidades

* 🔐 Sistema de login simulado (LocalStorage)
* 📝 Cadastro de usuário com validação
* 🎥 Listagem dinâmica de cursos (YouTube Embed)
* 🌙 Tema claro/escuro com persistência
* 📱 Layout totalmente responsivo
* 📂 Sidebar com navegação dinâmica
* 👤 Exibição do nome do usuário logado
* 🚪 Logout com controle de sessão
* ⚡ Renderização dinâmica via JSON
* 💫 Animações suaves e microinterações
